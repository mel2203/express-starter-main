Peanut Butter & Jelly API

Base URL: https://peanutbutterandjelly-backend-production.up.railway.app/

Authentication

Routes marked "Yes" under Auth need a token from /signup or /login. Tokens last 1 hour. Send it like this:

Authorization: Bearer <token>

Auth

MethodEndpointAuthBodyDescription
GET/db-checkNoCheck the database connection
POST/signupNouser_email, passwordCreate an account, returns a token
POST/loginNouser_email, passwordLog in, returns user_id, role and a token

Post visibility

  • Public: everyone
  • Friends-Only: the author and their accepted friends
  • Private: only the author

Status codes

  • 400: missing or invalid input, or a duplicate
  • 401: no token, or wrong email or password
  • 403: invalid token, or no permission
  • 404: not found
  • 500: server error
